SVG Cascade Isolation — Inline vs <img src="logo.svg">

Both cards wrap their SVG in a host element carrying color: red. The inline SVG uses fill="currentColor", so it inherits the red (the cascade crosses into it). The image SVG is a separate, isolated document and keeps its own color (blue, from the file's explicit fill) — rendered by resvg.

1. Inline SVG (svg_engine)

The <svg> lives in the host DOM and shares its CSS cascade.

■ Expected: RED ring — host color cascades in.

2. SVG as image (resvg)

<img src="logo.svg"> loads a separate, isolated document (the file has fill="#007aff").

■ Expected: BLUE ring — its own file color; host color must NOT cascade in.
