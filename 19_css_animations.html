SVG - CSS Animations

1. CSS Keyframe Attributes (@keyframes fill, opacity, r)

Tests internal CSS @keyframes controlling SVG native attributes like fill, r, and opacity.

2. CSS Transforms & Origins (transform-origin)

Tests CSS rotate and scale transforms utilizing explicit pixel-based transform-origin centers.

3. Interactivity & Transitions (:hover state)

Tests smooth state transitions triggered by pointer hover events (:hover) on shapes and text elements.

4. CSS Custom Properties & Staggered Text Animations

Tests CSS variables (var(--main-color)) animated via @property alongside staggered keyframe sequences for multi-language text.
