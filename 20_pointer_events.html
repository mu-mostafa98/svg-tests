SVG - Pointer Events

1. Click-Through Behavior (pointer-events: none vs auto)

Tests event passthrough: the left circle remains interactive under a transparent pointer-events="none" overlay, while the right is blocked.

2. Fill & Stroke Precision (visibleFill vs visibleStroke)

Tests granular interaction zones using visibleStroke (edge only), visibleFill (interior only), and all.

3. Affordance & Cursors (cursor property)

Tests pointer feedback cues using CSS cursor definitions (grab, crosshair, not-allowed) directly on SVG sub-elements.

4. Internationalization & Text Hit Targets

Tests mouse hit-testing, hover bounds, and event capture on localized multi-language text nodes and grouped sub-trees.
