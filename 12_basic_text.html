SVG - Basic Text

1. Text Anchoring (text-anchor: start, middle, end)

Tests horizontal positioning relative to coordinate origins using text-anchor properties (left, center, right).

2. Sub-String Styling & Positioning (<tspan> dx, dy, rotate)

Tests localized styling, relative coordinate shifts (dx, dy), and individual character rotation within <tspan> elements.

3. Vertical Alignment (dominant-baseline)

Tests vertical text alignment against a baseline using dominant-baseline parameters.

4. Internationalization (English, Chinese, Arabic RTL)

Tests multi-language Unicode rendering including left-to-right (LTR) Chinese and right-to-left (RTL) Arabic text directionality.
