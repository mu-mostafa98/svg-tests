SVG - Image Element (<image>)

1. Basic <image> (data URI, scaled to 100×100)

Loads a PNG data URI and renders it at an explicit width/height inside a reference frame.

2. Aspect: width-only vs. explicit stretch

With only width set, height preserves the source aspect ratio; with both set, the image is stretched.

3. transform attribute (translate + rotate)

The transform attribute applies on top of the image's own x/y/width/height positioning.

4. opacity + clip-path on <image>

An image participates in clip-path (rounded corner) and opacity just like a shape.

5. filter (feGaussianBlur) on <image>

Filters apply to the image's rendered pixels through the same group-wrapping path as shapes.

6. mask on <image>

An image can be masked (a black circle punches a hole in the white mask region).
