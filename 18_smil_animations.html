SVG - SMIL Animations

1. Property & Color Interpolation (<animate>)

Tests basic property transitions including positional offsets, dimensions, colors, and font sizing using <animate>.

2. Coordinate Transformations (<animateTransform>)

Tests 2D matrix manipulation over time using <animateTransform> for continuous rotation, scaling, and skewing.

3. Path Trajectory Motion (<animateMotion path="...">)

Tests object translation along complex <path> trajectories using <animateMotion> with rotate="auto" alignment.

4. Keyframes (keyTimes & keySplines) & Text Animation

Tests cubic bezier easing via keyTimes / keySplines and declarative animation applied to multi-language text nodes.
