SVG Engine Test Suite: Complex Shapes — Radial Gradients (all fallback to vello)

Each card renders the same radial-gradient feature on all four complex shapes (line, polygon, polyline, path). None of these shapes is native-gradient capable — the engine can only emit a native gradient inside a rect/circle/ellipse, so every case here rasterizes on the CPU (vello). The feature set mirrors 25_basic_shapes_radial_gradient.html so testers can compare native vs fallback rendering of the identical gradient.

All features fall back to vello (complex shapes have no native gradient path)

Test 26.1: Default Concentric Fallback

Expect: Concentric blue→green radial from each shape's center.

Test 26.2: objectBoundingBox Stretch Fallback

Expect: The radial stretches to each shape's bounding box, so wide shapes show flattened elliptical rings.

Test 26.3: userSpaceOnUse Aspect Fallback

Expect: One shared radial (center 50,50, radius 45) in canvas space; each shape shows a different window, aspect preserved.

Test 26.4: Spread Method — Pad Fallback

Expect: Central blue→yellow disc; everything past 25% radius clamps to solid yellow.

Test 26.5: Spread Method — Repeat Fallback

Expect: Concentric rings with a hard yellow→blue reset at every 25% interval.

Test 26.6: gradientTransform Fallback

Expect: The circle squashed into a horizontal ellipse by scale(1 0.6); indigo→pink rings follow.

Test 26.7: Multi-stop & Opacity Fallback

Expect: Red core fading through semi-transparent yellow to green edge.

Test 26.8: Spread Method — Reflect Fallback

Expect: Mirrored target-board rings alternating blue↔yellow (reflect is doubly fallback here).

Test 26.9: color-interpolation=linearRGB Fallback

Expect: Blue→green in linearRGB space (smoother mid-tones than sRGB).

Test 26.10: Offset Focal Point (fx/fy) Fallback

Expect: A white hotspot shifted to the upper-left while the outer rings stay centered.

Test 26.11: Focal Radius (fr) Fallback

Expect: A solid purple core disk spanning 15% before blue interpolation begins.
