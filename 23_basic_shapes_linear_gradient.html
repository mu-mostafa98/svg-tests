SVG Engine Test Suite: Basic Shapes — Linear Gradients (Native vs Fallback)

Each card renders the same linear-gradient feature on all three basic shapes (rect, circle, ellipse) that the SVG engine can render as a native WebRender gradient. Part 1 lists features that are native-eligible; Part 2 lists features that fall back to CPU rasterization (vello).

Part 1 — Linear gradient features that CAN be native (WebRender)

Test 23.1: Default Horizontal Native

Expect: All three shapes blend left-to-right from blue to green. Omitting x1/y1/x2/y2 must resolve to the default horizontal vector.

Test 23.2: Vertical (Axis-Aligned) Native

Expect: All three shapes blend top-to-bottom from red to orange. A perfectly axis-aligned vector renders natively.

Test 23.3: Diagonal Native

Expect: All three shapes blend diagonally from top-left (purple) to bottom-right (light blue).

Note (known bug): diagonal linear gradients are native-eligible, but WebRender's cached (Indirect) path currently renders them vertical.

Test 23.4: Multiple Color Stops Native

Expect: Four-band progression left-to-right: red, yellow, green, blue. Any number of stops maps to native WebRender stops.

Test 23.5: Stop Opacity Native

Expect: Dark overlay solid at the edges, fading to near-transparent in the center. Per-stop alpha is folded into the native stop color.

Test 23.6: Spread Method — Pad Native

Expect: Blend runs between 30% and 70%; areas outside are clamped to solid blue / solid yellow. Maps to native ExtendMode::Clamp.

Test 23.7: Spread Method — Repeat Native

Expect: Sawtooth repeating bands: green resets sharply to purple at each 20%-interval boundary. Maps to native ExtendMode::Repeat.

Test 23.8: Units — objectBoundingBox Native

Expect: Each shape's own bounding box is the gradient space — all three run blue→orange across their own width.

Test 23.9: Units — userSpaceOnUse Native

Expect: One shared coordinate space across the whole 100×100 canvas — every shape shows the same blue→orange window.

Test 23.10: gradientTransform Native

Expect: The horizontal vector is rotated 30° about each shape's center, producing a tilted indigo→pink blend. The transform is folded into the native endpoints.

Part 2 — Linear gradient features that CANNOT be native (fallback to vello)

Test 23.11: Spread Method — Reflect Fallback

Expect: Mirrored ribbons alternating green↔purple. WebRender has no ExtendMode::Reflect, so this rasterizes on the CPU (vello).

Test 23.12: color-interpolation=linearRGB Fallback

Expect: Blue→green but interpolated in linearRGB (physically smoother mid-tones). WebRender interpolates sRGB only, so this falls back to vello.
