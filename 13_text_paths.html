SVG - Text on Paths

1. Basic Curve Text Alignment (href reference to <path>)

Tests basic text attachment to a curved <path> reference using <textPath href="...">.

2. Path Positioning (startOffset & text-anchor)

Tests text alignment along a cubic path trajectory using startOffset percentages combined with text-anchor.

3. Circular Path & Multi-Language Rendering

Tests continuous text wrapping along circular closed paths with multi-language glyph support.

4. Advanced Attributes (side & Method spacing)

Tests path trajectory side switching using the side="left|right" attribute to flip text relative to direction.
