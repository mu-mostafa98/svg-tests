SVG - Coordinate Transforms

1. Translation & Non-Uniform Scaling (translate, scale)

Tests basic coordinate shifting via translate(x, y) and axis-specific resizing via scale(sx, sy).

2. Rotation & Pivot Points (rotate(deg), rotate(deg, cx, cy))

Tests rotate() around the origin (0,0) versus explicit pivot coordinates (cx, cy).

3. Skewing & Affine Matrix (skewX, skewY, matrix)

Tests axis shear via skewX()/skewY() and full 2D affine transformations via 6-parameter matrix().

4. Nested Transform Inheritance (Cumulative <g> Transforms)

Tests multi-level group hierarchy where child elements accumulate parent translation, rotation, scaling, and skewing.
