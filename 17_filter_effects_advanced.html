SVG - Advanced Filter Effects

1. Procedural Noise (<feTurbulence> type & baseFrequency)

Tests procedural noise generation using <feTurbulence> comparing fractalNoise vs turbulence modes.

2. Displacement Mapping (<feDisplacementMap>)

Tests geometric displacement distortion on vector paths and multi-language text using <feDisplacementMap>.

3. Kernel Convolution Matrices (<feConvolveMatrix>)

Tests spatial pixel neighborhood transformations using <feConvolveMatrix> for 3x3 embossing and edge detection kernels.

4. 3D Lighting Effects (<feDiffuseLighting> & <feSpecularLighting>)

Tests simulated 3D light sources using <feDiffuseLighting>, <feSpecularLighting>, and directional <feDistantLight>.
