SVG Engine Test Suite: Vertex Markers & Orientations

Test 8.1: Start, Mid, and End Vertex Mapping

Expect: A straight horizontal line. The start point has a red dot, the center vertex has a blue square, and the end point has a green arrow pointing right.

Test 8.2: Directional Auto-Rotation

Expect: A path with a purple arrow at its final terminal vertex. The arrow head must rotate dynamically to align perfectly with the incoming diagonal path tangent angle.

Test 8.3: orient="auto-start-reverse"

Expect: A line with orange arrows at both ends pointing outwards away from the shaft. The start marker flips 180 degrees automatically relative to path direction.

Test 8.4: Fixed Rotation Angle Override

Expect: A purple arrow positioned in the center. Despite sitting on a horizontal path, the arrow must be locked at a sharp 45-degree downward angle.

Test 8.5: markerUnits="strokeWidth" (Default)

Expect: Two lines with green end squares. The marker square on the bottom line must be three times larger than the top marker because it inherits the host line thickness.

Test 8.6: markerUnits="userSpaceOnUse"

Expect: Yellow square markers on both paths must be exactly identical in size. Tests if the engine decouples marker scale bounds from line thickness parameters.

Test 8.7: Polyline/Polygon Node Mapping

Expect: A zigzag profile line. Blue marker circles must be positioned on every single internal node vertex bend point (excludes the absolute start and end tips).

Test 8.8: Zero-Length Segments (Degenerate Paths)

Expect: A single red dot placed at (50,50). Verifies if your math engine safely catches internal divide-by-zero errors when vector slopes cannot be computed.
