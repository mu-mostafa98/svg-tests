SVG - Clipping Paths

1. Basic Geometric ClipPath (circle & rect clipping)

Tests basic shape boundary constraint using <clipPath> containing standard <circle> and <rect> geometry.

2. Path & Transformed Clip Shapes

Tests clipping with non-regular <polygon> paths and transformed <g> clip containers.

3. Text Clip Paths (English, Chinese, Arabic)

Tests using <text> nodes (including LTR, CJK, and RTL Arabic) as operational <clipPath> masks.

4. ClipPath Units (objectBoundingBox) & Nesting

Tests relative coordinate system scaling via clipPathUnits="objectBoundingBox" alongside nested clip-path composition.
