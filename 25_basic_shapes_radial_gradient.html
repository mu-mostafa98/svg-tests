SVG Engine Test Suite: Basic Shapes — Radial Gradients (Native vs Fallback)

Each card renders the same radial-gradient feature on all three basic shapes (rect, circle, ellipse). Part 1 lists features the engine can render as a native WebRender radial gradient; Part 2 lists features that fall back to CPU rasterization (vello).

Part 1 — Radial gradient features that CAN be native (WebRender)

Test 25.1: Default Concentric Native

Expect: Concentric blue→green radial from each shape's center (cx=50%, cy=50%, r=50% defaults). Concentric radials are native-eligible.

Test 25.2: objectBoundingBox Stretch Native

Expect: The radial stretches to each shape's own bounding box, so the wide rect and ellipse show flattened elliptical rings.

Test 25.3: userSpaceOnUse Aspect Native

Expect: One shared radial (center 50,50, radius 45) in canvas space; each shape shows a different window into it. Aspect ratio is preserved.

Test 25.4: Spread Method — Pad Native

Expect: A central blue→yellow disc; everything past 25% radius clamps to solid yellow (native ExtendMode::Clamp).

Test 25.5: Spread Method — Repeat Native

Expect: Concentric rings with a hard yellow→blue reset at every 25% interval (native ExtendMode::Repeat).

Test 25.6: gradientTransform Native

Expect: The circle is squashed into a horizontal ellipse by scale(1 0.6); indigo→pink rings follow.

Test 25.7: Multi-stop & Opacity Native

Expect: Red core fading through semi-transparent yellow to green edge. Multi-stops and per-stop alpha are native.

Part 2 — Radial gradient features that CANNOT be native (fallback to vello)

Test 25.8: Spread Method — Reflect Fallback

Expect: Mirrored target-board rings alternating blue↔yellow. No native ExtendMode::Reflect → vello.

Test 25.9: color-interpolation=linearRGB Fallback

Expect: Blue→green in linearRGB space (smoother mid-tones). WebRender interpolates sRGB only → vello.

Test 25.10: Offset Focal Point (fx/fy) Fallback

Expect: A white hotspot shifted to the upper-left while the outer rings stay centered. Offset focal is concentric-incompatible → vello.

Test 25.11: Focal Radius (fr) Fallback

Expect: A solid purple core disk spanning 15% before blue interpolation begins. Non-zero fr is unsupported natively → vello.
