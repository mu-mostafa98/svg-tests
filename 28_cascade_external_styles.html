SVG Cascade From Outside the Body

Only <svg>, <g>, and <path>, styled only with fill and stroke. All CSS lives in the <style> block above — never inside an <svg>.

1. Element selector (.case-element path)

Expected: green rectangle with a darker green outline.

2. Class selector (.shape-orange)

Expected: orange triangle.

3. Specificity — ID beats class (#shape-blue over .shape-red)

Expected: blue diamond (ID wins over the red class).

4. Inheritance through a <g> (.group-purple)

Expected: purple rectangle and triangle (both inherit fill/stroke from the group).

5. Inline style beats an external class

Expected: red teardrop (inline fill overrides the external green class).
