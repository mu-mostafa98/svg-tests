SVG - Symbols & Use

1. Basic Defs & Use Instance Offset (x, y, transform)

Tests basic element instantiation via <defs> and <use href="..."> positioned with x/y attributes and cumulative transforms.

2. Symbol Definitions with Internal ViewBox (viewBox="0 0 100 100")

Tests <symbol> definitions scaling automatically to fit the target width and height bounds declared on the <use> element.

3. Presentation Attribute Overrides on <use> Instances

Tests property inheritance through shadow DOM boundaries when fill, stroke, and opacity are specified directly on the <use> tags.

4. Nested Symbol Instantiation & Composition

Tests multi-level nesting where a <use> tag instantiates a group that contains secondary <use> references.
