SVG - Filter Effects Basic

1. Gaussian Blur (<feGaussianBlur stdDeviation>)

Tests basic pixel defocusing using <feGaussianBlur> with uniform and single-axis (horizontal) stdDeviation values.

2. Drop Shadow (<feDropShadow> on Shapes & Text)

Tests localized drop shadows and radial glows applied to vector paths and multi-language text using <feDropShadow>.

3. Color Matrix Transformations (<feColorMatrix>)

Tests RGBA channel recalculations using <feColorMatrix> modes: matrix transform, hue rotation, and saturation boosting.

4. Filter Pipelines (<feOffset> + <feBlend>)

Tests multi-stage filter pipelines combining <feOffset>, <feGaussianBlur>, <feColorMatrix>, and <feBlend>.
