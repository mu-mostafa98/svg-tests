SVG - Embedded Content

1. HTML in SVG (<foreignObject>)

Tests embedding native HTML elements and CSS layout models (Flexbox, buttons) inside an SVG viewport via <foreignObject>.

2. Embedded Raster Images (<image>)

Tests embedded raster image objects (<image>) using inline data URIs and positioning alongside native SVG vector elements.

3. Nested SVG Viewports (<svg> inside <svg>)

Tests nested independent SVG viewports (<svg> within <svg>) establishing isolated coordinate spaces and clipping bounds.

4. Multi-Language Rich Text (<foreignObject>)

Tests internationalized multi-language rich text (LTR and RTL) rendered using standard HTML layout nodes inside a <foreignObject> container.
