SVG currentColor Test Suite

Use this page to verify if your rendering engine correctly resolves the currentColor value dynamically and via inheritance.

Case 1: Direct CSS Inheritance (Fill & Stroke)

Expected: Rectangle fill and Circle stroke should both be Red (#ff0000).

Case 2: Overriding Parent Color via Class

Expected: Rectangle should be Blue (#0000ff) because the SVG overrides its parent's red color.

Case 3: Inline Style Inheritance

Expected: Triangle should be Orange (#ffa500) defined via inline style on the SVG tag.

Case 4: Color Presentation Attribute

Expected: Circle should be Purple (#800080) resolved from the color="" attribute on the SVG root.

Case 5: Nested Canvas Inheritance (<g> tags)

Expected: Top rect is Red (inherits body/parent). Bottom rect is Teal (#008080) (inherits <g> style override).

Case 6: Dynamic CSS Interaction (:hover)

Expected: Shapes should be Green (#008000) normally, but turn Magenta (#ff00ff) when hovering over the SVG framework.

Case 7: SVG Gradients

Expected: Gradient goes from Bright Orange-Red (#ff3300) on the left to solid transparent white on the right.
