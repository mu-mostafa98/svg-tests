SVG Engine Test Suite: Complex Shapes — Linear Gradients (all fallback to vello)

Each card renders the same linear-gradient feature on all four complex shapes (line, polygon, polyline, path). None of these shapes is native-gradient capable — the engine can only emit a native gradient inside a rect/circle/ellipse, so every case here rasterizes on the CPU (vello). The feature set mirrors 23_basic_shapes_linear_gradient.html so testers can compare native vs fallback rendering of the identical gradient.

All features fall back to vello (complex shapes have no native gradient path)

Test 24.1: Default Horizontal Fallback

Expect: Every shape blends left-to-right from blue to green (line and polyline via stroke; polygon and path via fill).

Test 24.2: Vertical (Axis-Aligned) Fallback

Expect: Top-to-bottom red→orange blends. Axis-aligned is still vello here — the shape (not the vector) is what excludes native.

Test 24.3: Diagonal Fallback

Expect: Diagonal top-left (purple) → bottom-right (light blue). vello renders diagonal gradients correctly.

Test 24.4: Multiple Color Stops Fallback

Expect: Four-band red/yellow/green/blue progression across every shape.

Test 24.5: Stop Opacity Fallback

Expect: Dark edges fading to near-transparent centers, so the dashed svg border shows through the middle of each shape.

Test 24.6: Spread Method — Pad Fallback

Expect: Blend between 30%–70%, clamped to solid blue / solid yellow outside that band.

Test 24.7: Spread Method — Repeat Fallback

Expect: Sawtooth repeating bands with hard green→purple seams every 20% interval.

Test 24.8: Units — objectBoundingBox Fallback

Expect: Each shape's own bounding box drives its blue→orange gradient.

Test 24.9: Units — userSpaceOnUse Fallback

Expect: One shared coordinate space — every shape shows the same full-width blue→orange window.

Test 24.10: gradientTransform Fallback

Expect: A 30°-rotated indigo→pink blend across each shape.

Test 24.11: Spread Method — Reflect Fallback

Expect: Mirrored green↔purple ribbons (reflect is unsupported natively too, so it is doubly fallback).

Test 24.12: color-interpolation=linearRGB Fallback

Expect: Blue→green interpolated in linearRGB (smoother mid-tones than sRGB).
