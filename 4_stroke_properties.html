SVG Engine Test Suite: Stroke Properties & Dashes

Test 4.1: Stroke Line Caps

Expect: Black line (butt) fits exactly between red lines. Blue (round) and Green (square) caps must extend past red boundaries by exactly 6px (half of stroke-width).

Test 4.2: Stroke Line Joins

Expect: Top-left corner is a sharp pointed spike (miter). Bottom-left corner is smoothly rounded. Right corner is sliced off flat (bevel).

Test 4.3: Miter Limit Thresholds

Expect: Top orange spike must cut off flat near the point because its miter ratio exceeds 2. Bottom purple spike must render as a complete sharp needle tip.

Test 4.4: Symmetrical Dash Array

Expect: Top blue line has alternating dashes and spaces of equal length. Bottom purple line has long segments separated by small gaps.

Test 4.5: Odd-Numbered Dash Repeating

Expect: Alternating sequence: Long dash (15), space (5), short dash (2), space (15), long dash (5), space (2). Repeating sequence must match layout specs.

Test 4.6: Dash Offset Movement

Expect: Shifted dash intervals. Red line shifts left by 10px compared to black line. Orange line shifts right by 10px.

Test 4.7: Dashes on Curves & Arcs

Expect: Purple dashed circle pattern. Dashes must bend uniformly along the circumference arc path without stretching distortion.

Test 4.8: Intersecting Caps & Dashes

Expect: A horizontal chain of perfectly circular yellow beads. Zero length plus round caps creates standard vector dots.

Test 4.9: Zero Stroke Width Handling

Expect: Only the inner green center circle. Zero or negative stroke-width parameters must disable border rendering entirely.

Test 4.10: Vector Effect (Non-Scaling)

Expect: The blue rectangle stroke multiplies by 3 becoming extremely thick (6px). The red rectangle border **must remain exactly 2px thin** despite the parent transform matrix scaling.

Test 4.11: Style Group Inheritance

Expect: Top line is purple & thick with round caps. Middle line is orange but retains thick rounded ends. Bottom line completely overrides properties to thin green with flat cut endpoints.
