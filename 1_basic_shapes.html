SVG Engine Test Suite: Basic Shapes Primitives

Test 1.1: Standard Rectangle

Expect: Sharp green rectangle from (10,10) to (90,70) with a black outline.

Test 1.2: Rounded Rectangle (rx, ry)

Expect: Blue square with perfectly uniform 15px rounded corners.

Test 1.3: Rect Clamped Corners (rx > width/2)

Expect: A perfect circle. Spec dictates rx/ry must scale down proportionally if they overlap.

Test 1.4: Rect Invalid Dimensions (Zero/Negative)

Expect: Blank canvas except for the orange center line. Zero or negative width/height disables rendering.

Test 1.5: Standard Circle

Expect: Yellow circle centered precisely at (50,50) extending to borders.

Test 1.6: Circle Implicit Center

Expect: Top-left quadrant of an orange circle centered at (0,0).

Test 1.7: Circle Invalid Radius

Expect: Only the vertical green line. r <= 0 disables rendering entirely.

Test 1.8: Standard Ellipse

Expect: Purple oval wider horizontally than vertically, centered at (50,50).

Test 1.9: Standard & Thick Lines

Expect: Two lines crossing. Red line must be noticeably thicker and sit on top.

Test 1.10: Open Polyline

Expect: Continuous blue zigzag line. The shape must stay completely open (no fill connecting start and end).

Test 1.11: Polyline Implicit Fill

Expect: Black zigzag line with the enclosed region automatically filled in green, but no stroke closing line.

Test 1.12: Closed Polygon

Expect: Red triangle. The stroke must cleanly close the path at the bottom vertices.

Test 1.13: Self-Intersecting Polygon

Expect: A solid 5-point star filled completely with yellow because of the `nonzero` rule.

Test 1.14: Polygon EvenOdd Fill Rule

Expect: A 5-point star where the inner central pentagon remains transparent/hollow.

Test 1.15: Malformed Coordinate Whitespace

Expect: Engine should parse valid pairs safely up to the junk data, fallback safely, or drop the shape depending on strictness. (Standard browsers drop or parse a triangle).
